# Geist local

`geist-latin.woff2` é a fonte variável Geist Sans, copiada sem alteração do
Next.js 15.5.25 já instalado, em `next/dist/next-devtools/server/font/`.
O subset latino inclui os caracteres usados em português. Não há download
de fontes durante build ou execução da página.

Licença SIL Open Font License 1.1 em `Geist-OFL.txt`, obtida do repositório
oficial: https://github.com/vercel/geist-font/blob/main/OFL.txt.

Uso na Fase 2 limitado à rota `/visual-system`; a aplicação existente ainda
não foi migrada.
